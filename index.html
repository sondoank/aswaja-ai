💡 Berjalan Otomatis Tanpa API Key (Mode RAG Lokal)

Secara bawaan, prototipe ini sudah dilengkapi Mesin Sintesis RAG Lokal yang merangkum jawaban langsung dari Database Kitab & LBM NU serta pencarian situs nu.or.id.

Jika Anda memasukkan Google Gemini API Key di bawah ini, sistem akan mengaktifkan Gemini 2.5 Flash dengan System Prompt Aswaja An-Nahdliyah untuk penalaran percakapan yang jauh lebih luwes.

Disimpan secara lokal di browser Anda (LocalStorage). Dapatkan gratis di Google AI Studio.
